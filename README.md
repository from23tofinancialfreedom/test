# test

自动化脚本示例：`auto_course.py`

## 功能
- 默认使用 **Edge** 浏览器启动（不可用时自动回退 Chromium）。
- 自动点击首页右上角 **登录**，并尝试点击 **微信登录**，等待扫码。
- 登录后自动点击头像，进入主页/学习中心。
- 优先从“任务日历”里点击班级任务（如右侧“全天”链接），进入真正的班级课程页。
- 自动查找需要学习的班级并进入。
- 在班级课程列表中自动按“未完成”筛选，且支持**自动翻页查找课程**（每页约 4 门课）。
- 进入课程后自动学习视频小节，答题/测验类小节自动跳过。

## 傻瓜版（一键启动，推荐）
> 只要本机有 Python，就可以直接一键跑。

- Windows：双击 `start.bat`
- Linux / macOS：执行
  ```bash
  ./start.sh
  ```

`start.py` 会自动做三件事：
1. 检测并安装 `playwright`（缺失时自动安装）
2. 安装/校验 `chromium` 浏览器内核
3. 启动 `auto_course.py`

## 手动方式（进阶）
1. 安装依赖：
   ```bash
   pip install playwright
   python -m playwright install chromium
   ```
2. 运行脚本：
   ```bash
   python auto_course.py
   ```

## 说明
- 当前脚本基于页面文本关键词与通用选择器做识别，平台 UI 改版后可能需要微调。
- 默认尝试静音并将视频倍速设为较高值（浏览器/平台可能限制倍速上限）。
- 登录流程已做多重容错：登录按钮、微信登录入口、扫码等待、头像菜单进入。
